Release notes & checksum ↗
1

Download and move

Unzip the download and drag CodexBar.app into Applications. One universal build for both Mac architectures.

2

Sign in to Codex

Install Codex and sign in with ChatGPT. If needed, run codex login in Terminal. API-key usage is separate from subscription quota.

3

Open and carry on

Launch CodexBar. Quota refreshes every minute. Left-click opens no panel; right-click to refresh or quit.

A note on the first launch

This release is ad-hoc signed, not Apple-notarized. If macOS blocks it and you trust the source, try opening it once, then choose Open Anyway in System Settings → Privacy & Security. You can also build from source.
