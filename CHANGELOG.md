# Changelog

## 0.1.1

- Left-click now opens the refresh and quit menu; right-click no longer opens it.
- Open the status menu directly instead of simulating a button click.
- Show an immediate refresh indicator and disable repeated refresh requests while fetching.
- Show the last successful update time in the menu and tooltip.
- Update English and Chinese help text and website instructions.

## 0.1.0

- Initial release with a colored quota gauge, reset times, English and Simplified Chinese, and a universal macOS app.
